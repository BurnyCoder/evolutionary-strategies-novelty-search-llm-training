# Claim-by-claim scientific evidence map

This map applies to statements repeated in the overview, both papers, experiment summaries, figures, static and live dashboards, and the six Hub cards. Keys below identify independently generated evidence. Earlier audits are dated publications whose claims require the same primary evidence as any other statement.

| Reported changes in fitness explain the final checkpoint difference. | Unsupported causal attribution. | The optimizer implements Gaussian full-weight ES with normalized reward. | Supported as an adaptation. The original implementation's partially correlated layer noise and native arithmetic differ. [ES Algorithm 2 and Appendix A.1](https://arxiv.org/html/2509.24372v3) · [Pinned reward shaping](https://github.com/VsonicV/es-at-scale/blob/574a9d134da1ffce2a8bb812019899e5c96b588a/es_at_scale/utils/reward_shaping.py) · [Optimizer](../../src/novelty_es/optimizer.py) · [Coefficients](historical-verification-2026-11-26.json). |
| ExTra validates this experiment's estimator or predicts a positive outcome. | Unsupported. Its advantage equation adds a correctness-gated bonus after normalization in GRPO. Siblings come from different candidate models, prefix regeneration is absent, and the hybrid has no transferred performance guarantee. [ExTra section 4 and Appendix B](https://arxiv.org/html/2606.24994v1) · [Frozen amendment](../preregistration.md#amendment-a-source-aligned-weighting-before-either-trained-condition). |
| The memory implements a frozen correct-sibling/history reference pool. | The code and synthetic arithmetic checks cover gating, self exclusion, empty pools and negative cosines. [Local memory](../../src/novelty_es/novelty.py) · [Pinned upstream helper](https://github.com/allen4747/extra/blob/ea53e68036356f8f276e261e886fbbc102633be3/verl/recipe/extra/curiosity_memory.py) · [Archive measurements](archive-2026-11-26.json). |

| Greedy and temperature-one sampling are fully described by temperature, top-p and top-k. | Incomplete. Both modes also inherit the upstream repetition penalty. [Pinned defaults](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct/blob/7ae557604adf67be50417f59c2c2f167def9a775/generation_config.json) · [Generation implementation](../../src/novelty_es/models.py) · [Transformers documentation](https://huggingface.co/docs/transformers/main_classes/text_generation). |

## Coverage of presentations and scientific records

The [presentation calculations](presentations-2026-11-26.json) list the checked surfaces. The [local and web citation inventory](citations-2026-11-26.json) checks destinations. The [Hub](publication-2026-11-26.json) and [GitHub and Pages](deployment-2026-11-26.json) receipts verify the published files against their staged versions.

The README, both experiment reports, aggregate, plots, PDF papers, website snapshots and Hub cards share the reporting entry point. Tables retain the historical scores and explicitly identify the balanced regrade. The plotted accuracy intervals derive from the same problem-bootstrap arrays. Training curves describe candidate populations; validation curves describe unperturbed checkpoints. All plots use labeled axes. Example responses take the first fixed primary problems across conditions. The [reporting implementation](../../src/novelty_es/reporting.py), [generated pilot](../experiment-pilot.md) and [generated recovery](../experiment-continuation-seed0-gen100.md) expose these definitions.

Frozen registrations and older receipts retain their original wording. Their signed dates, predictions and referenced configurations remain historical evidence. Prior dashboard screenshots, audit verdicts and passing tests alone cannot establish scientific accuracy. The audit uses event logs, problems, checkpoint tensors and public server records as primary evidence. Software comments and tests describe the implemented or intended behavior; neither supplies independent experimental observations.
